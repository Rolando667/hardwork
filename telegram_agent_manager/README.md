# Telegram Agent Manager

Десктопний застосунок для Windows, який дозволяє керувати кількома
Telegram-ботами («агентами») з одного вікна. Кожен агент приймає
повідомлення у Telegram, передає їх у **Claude** (Anthropic API) із власним
системним промтом і повертає відповідь користувачу — усе без жодного рядка коду.

## Можливості

- 🤖 **Необмежена кількість агентів** — у кожного власний Telegram-токен,
  ключ Claude, модель, системний промт, температура, `max_tokens` і глибина
  пам'яті діалогу.
- ▶️ **Незалежний запуск/зупинка** кожного агента. Падіння одного бота не
  впливає на роботу інших.
- 🔒 **Шифрування ключів** (Fernet). Токени й ключі ніколи не зберігаються
  у відкритому вигляді; ключ шифрування виводиться з майстер-пароля (scrypt).
- 🧪 **Тестовий міні-чат** — перевірка промта прямо в програмі, без Telegram.
- 📜 **Логи в реальному часі** з фільтрами за ботом і рівнем + ротація у файл.
- 🌗 **Темна/світла тема**, згортання в трей, автозапуск із Windows.
- 🔁 **Стійкість**: авто-перепідключення до Telegram, ретраї Claude
  (429/529) з експоненційною затримкою, зрозумілі повідомлення про помилки.
- 💾 **Експорт/імпорт** усієї конфігурації в зашифрований файл-бекап.

## Технологічний стек

| Компонент        | Технологія                          |
|------------------|-------------------------------------|
| GUI              | PySide6 (Qt) + кастомна QSS-тема     |
| Telegram         | aiogram 3.x (long polling)          |
| Claude           | офіційний SDK `anthropic`           |
| Async ↔ Qt       | qasync                              |
| Зберігання       | SQLite (`config.db`)                |
| Шифрування       | cryptography (Fernet + scrypt)      |
| Пакування        | PyInstaller                         |

> **Чому aiogram + long polling, а не webhook?** Застосунок локальний, без
> публічного сервера з білою IP-адресою, тому webhook непридатний — long
> polling працює з будь-якої машини за NAT.

## Структура проєкту

```
telegram_agent_manager/
├── main.py                  # точка входу, інтеграція qasync
├── ui/
│  ├── main_window.py        # головне вікно: Агенти / Логи / Налаштування, трей
│  ├── bot_card.py           # картка агента + тестовий міні-чат
│  ├── master_dialog.py      # діалог майстер-пароля
│  ├── theme.py              # завантаження теми з підстановкою кольорів
│  └── styles.qss            # кастомна QSS-тема (токени кольорів)
├── core/
│  ├── bot_worker.py         # логіка одного агента: aiogram + anthropic
│  ├── claude_client.py      # клієнт Claude з ретраями та проксі
│  ├── storage.py            # SQLite + шифрування
│  ├── logger.py             # логування у файл + у GUI
│  └── paths.py              # шляхи (%APPDATA%\TelegramAgentManager)
├── requirements.txt
├── build.bat                # збірка в .exe
└── README.md
```

Дані застосунку зберігаються в `%APPDATA%\TelegramAgentManager\`
(`config.db` та тека `logs\`).

## Запуск у режимі розробки

Потрібен **Python 3.11+**.

```bash
# 1. Клонувати / розпакувати проєкт і зайти в теку
cd telegram_agent_manager

# 2. Створити віртуальне середовище
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate

# 3. Встановити залежності
pip install -r requirements.txt

# 4. Запустити
python main.py
```

При першому запуску програма попросить **придумати майстер-пароль** — ним
шифруються всі ключі. Пароль ніде не зберігається; відновити його неможливо,
тому не втрачайте його.

## Як користуватися

1. **＋ Додати агента** → у правій панелі заповніть:
   - **Назва** — довільна, тільки для вас.
   - **Telegram Bot Token** — отримайте у [@BotFather](https://t.me/BotFather).
   - **Claude API Key** — можна лишити порожнім, тоді буде використано
     глобальний ключ з вкладки «Налаштування».
   - **Модель**, **системний промт**, **температуру**, **max_tokens**,
     **глибину пам'яті**.
2. Натисніть **💾 Зберегти**, потім **▶ Запустити**.
3. Напишіть боту в Telegram — він відповість через Claude.
4. **🧪 Тест** — перевірити промт без Telegram.
5. Вкладка **Логи** — події в реальному часі.

## Збірка в .exe

На Windows просто запустіть:

```bat
build.bat
```

Скрипт створить віртуальне середовище, встановить залежності й збере
самостійний файл **`dist\TelegramAgentManager.exe`**.

Або вручну:

```bat
pyinstaller --onefile --windowed --icon=app.ico ^
    --name "TelegramAgentManager" ^
    --add-data "ui/styles.qss;ui" ^
    --collect-all aiogram --collect-all anthropic ^
    main.py
```

Готовий `.exe`:

- **не відкриває консольне вікно** (`--windowed`);
- запускається **подвійним кліком** на чистому Windows **без встановленого
  Python**;
- усе необхідне (стилі, залежності) упаковано всередину.

> Файл `app.ico` не обов'язковий — якщо його немає, збірка пройде зі
> стандартною іконкою. Покладіть свій `app.ico` поряд із `main.py`, щоб
> задати власну.

## Безпека

- Майстер-пароль → scrypt → ключ Fernet. Сам пароль не зберігається, лише
  зашифрований маркер для перевірки.
- Токени/ключі в БД — тільки у зашифрованому вигляді; у пам'яті —
  на час роботи.
- У логи ключі не потрапляють.
- Бекап шифрується окремим паролем, який ви задаєте під час експорту.
